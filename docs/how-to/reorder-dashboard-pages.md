# Reorder dashboard pages

With two or more pages and write access:

1. Open the page dropdown in the dashboard header. On a phone, use the small
   down-chevron button.
2. Choose **Reorder pages**.
3. Use the up and down buttons beside each name to move it. Each move saves
   automatically; wait for **Saving order…** to finish before the next move.
4. Choose **Done** to return to page selection.

For example, move Docked above Underway to arrange **Anchored → Docked →
Underway → Cluster Preview**. Keyboard users can Tab to a movement button and
activate it with Enter or Space. First/last pages cannot move past the ends.

The sidebar and dropdown update together, and the selected page stays open.
The order is shared across devices and survives a restart. Reload other open
devices to pick up the change. New pages appear at the end.

If saving fails, the previous order remains visible and an error explains the
failure. Retry once the connection or storage issue is fixed. If another device
has created or deleted a page, reload the dashboard before trying again.

Reordering is separate from widget layout mode and works on phones and tablets.
When sign-in is enabled, it requires readwrite or admin access.
