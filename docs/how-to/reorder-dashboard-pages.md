# Reorder dashboard pages

With two or more pages and write access:

1. Open the page dropdown in the dashboard header. On a phone, use the small
   down-chevron button.
2. Choose **Reorder pages**.
3. Move a name with the up and down buttons beside it. Each move saves as you
   make it; wait for **Saving order…** to finish before the next one.
4. Choose **Done** to return to page selection.

Move Docked above Underway, for example, to end up with **Anchored → Docked →
Underway → Cluster Preview**. Keyboard users can Tab to a movement button and
press Enter or Space. The first and last pages do not move past the ends.

The sidebar and the dropdown update together, and the page you were on stays
open. Every device shares the order and it survives a restart, though other
devices already open need a reload to pick it up. New pages land at the end.

If a save fails, the previous order stays on screen and an error explains
why. Retry once the connection or storage problem is fixed. If another device
has created or deleted a page in the meantime, reload the dashboard before
trying again.

Reordering is nothing to do with tile layout mode, and it works on phones and
tablets. With sign-in enabled it needs readwrite or admin access.
