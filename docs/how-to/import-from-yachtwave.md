# Import from YachtWave

This brings the equipment, spares, service log, notes and documents you keep
in YachtWave into Helmcentral, so you don't have to type them in again. Allow
half an hour for a boat with a few years of history. Most of that is saving
and pasting documents and photos.

You need YachtWave's Vessel Export for the boat, saved as an HTML file.

## Start the import

1. Open **Settings → Import**.
2. Select **Import from YachtWave**.
3. Drop the export file on the page, or pick it.

If the file isn't a YachtWave Vessel Export, the page says so and nothing is
kept.

## Work through the pages

Select **Next** to save each page and move on. **Back** and the step list at
the top take you to earlier pages without losing anything.

1. **What is in the export.** How many records each section holds and what
   will be left behind: notes holding a password, checklists, and any sections
   Helmcentral has no home for. **Worth a look** lists duplicates, placeholder
   names and figures that can't be right. Keep them in mind for the pages
   that follow.
2. **Vessel.** The particulars Helmcentral will store. Untick any you don't
   want, such as a displacement exported in the wrong unit. Figures that come
   from the boat's instruments are shown beside the live reading and marked
   **Differs** where they disagree. They aren't imported. Correct the
   instruments if they're wrong.
3. **Locations.** For each YachtWave location, pick an existing location, or
   **Create a new location**, or **Leave this location out**. A location you
   leave out is kept as text on each item's location detail.
4. **Equipment and spares.** For each item, **Create new**, **Use existing**
   to pair it with gear you already have, or **Skip**. Items flagged **Looks
   like a duplicate** start as skipped. A locker that lists several things
   comes in as a bin with one item per line.
5. **Maintenance log.** Untick entries you don't want. Where both engines have
   the same name, **Choose the equipment** for each entry the export leaves
   open, or pick **No equipment**. You can't go on until each ticked entry
   has one.
6. **Notes.** Notes and YachtWave tasks, which come in as notes. Untick any
   you don't want. Notes marked **Not imported** hold a password or wifi
   key and stay behind.
7. **One page per document or photo.** Select **Open in YachtWave**, save the
   file, then paste it on the page, drop it, or pick it. Or select **Skip**.
   Use **Attach to equipment** to put it on an item's record. Otherwise it's
   kept as a document on its own.
8. **Confirm.** A summary of what will be added. **Still to do** lists
   anything that blocks the import, with a button back to that page.
   Select **Import**.

When the import finishes, you get a list of everything created, each linking
to its record.

## Stopping partway

Your choices are saved each time you change page. Close the tab and come back
later from **Settings → Import → Resume**, on the same device. The import
opens at the first page with your choices intact.

**Abandon import** throws your choices away and adds nothing. Documents and
photos you have already pasted in stay in Documents.

## Importing a later export

Run the import again with the newer file. Anything already brought across is
marked **Already imported** and skipped, so only new records are added.

See [Import](../features/import.md) for what the import covers and what it
leaves out.
