# Run a stocktake

See [Inventory](../features/inventory-tracking.md#doing-a-stocktake) for
what a stocktake does and does not change on its own. These are the steps
for actually running one.

## Start

1. Open **Inventory → Stocktake**.
2. On an Android phone in Chrome, press **Start scanning** and leave the
   screen open - every tap from here on is picked up automatically. On any
   other device, click into the scan field instead; a keyboard-wedge
   barcode scanner plugged in works here too, or you can type a bin code
   by hand and press Enter.

## Work through a bin

1. Scan or tap the bin's own tag first, or type its code and press Enter.
   Its contents and photos appear below, so you can check things off by
   eye as well as by scanning.
2. Tap or scan each item's own tag as you find it. An item already filed
   in this bin is marked **Confirmed**.
3. An item that turns up recorded somewhere else shows where, with a
   **Move** button - press it to correct the record, or leave it alone if
   the item is only visiting and you don't want to move it.
4. When you're done with the bin, scan the next one's tag to switch to it.

Anything left under **Not seen this pass** when you move on is exactly
that: not scanned this time. Nothing changes for those items on its own -
go back for them, or accept that they weren't where you expected and
follow up by hand later.

## Add something you find along the way

Scanning something the system doesn't recognise is reported as such, never
silently dropped or guessed at. Use **Add to this bin** on the current
bin's page to record it properly with a name and a photo, the same as any
other new item, then carry on scanning.
